Soul Medic - "A Complete Health Care Solution"

Project Architechture

To Build our application we have used Three-tier(Three-Layer) Architechture.

Presentation Layer

(Frontend/UI Part)
  1. Html
  2. Css
  3. Javascript
  4. React
  5. Bootstrap

Bussiness Logic Layer

(Backend Part)
  1. Java(Java 8)
  2. Spring Boot
  3. Microservices Architechture
  4. Rest Api development
  5. Spring Data JPA
  6. Python

Data Access Layer

(Data Storage Part)
  1. MySQL Database
Other technologies used -
  1. For Testing - Junit Along with Mockito Framework.
  2. For Deployment - Docker
  3. Basic AWS Services.
  4. Integrated 3rd party Api's like Redox API,PayPal API etc.

Key Features of Soul-Medic

  1. Appointment Management
  2. Telemedicine/Video Consultation
  3. Health and Wellness Tracking
  4. In-App Chats
  5. Reminders & Notifications
  6. Electronic Health Records (EHR)
  7. Emergency Assistance
  8. Integration with Insurance Providers
  9. Family Health Profiles
  10. Premium Services
