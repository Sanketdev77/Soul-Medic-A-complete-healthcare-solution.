# Soul-Medic : A complete healthcare solution.
Domain – Health Care,
Team Size - 5 members

TECHNOLOGY STACK :-
Backend Technologies - Java 8, Spring Framework, Spring MVC, Spring Boot, Spring Data JPA,
Microservices Architecture, RESTful APIs.
Frontend Technologies - HTML5, CSS3, Bootstrap 5, Javascript & React.
Database Technology - RDBMS [MySQL].
Testing Framework - , JUnit & Mockito .
Version Control Tool - Git.
CI/CD Tools - Docker.

DESCRIPTION :-
As a collaborative effort within a skilled team, I spearheaded the development of Soul Medic, a
cutting-edge healthcare platform designed to revolutionize patient care. Leveraging Java
Spring, Spring Boot, Microservices, Rest Api’s, HTML, CSS, JavaScript, Bootstrap & React, we
crafted a comprehensive system offering Doctor Services, Staff Services, and Patient Services and
myriad of innovative features. Utilizing MySQL for storage and implementing architectural
components like API Gateway, Service Registry, and Circuit Breaker, I ensured the platform's
efficiency and reliability. Notable functionalities include telemedicine/video consultation,
empowering patients with remote healthcare access. Our platform also facilitates health and
wellness tracking, in-app chats for seamless communication, and comprehensive health
education resources. Additionally, we integrated reminders and notifications to enhance
patient engagement and adherence to healthcare regimens. Through meticulous attention to
detail and effective teamwork, we successfully created a robust healthcare solution that
embodies the future of patient-centered care.
